# Power BI Data Modeling Portfolio Project

## Overview

This project focuses on transforming 23 messy source tables into a clean and scalable Star Schema data model in Power BI.

Instead of focusing on dashboard creation, the primary objective was to build a robust semantic model that supports business reporting, analysis, and future scalability.

## Project Objectives

- Explore and understand complex source tables
- Identify Fact and Dimension tables
- Design a scalable Star Schema
- Create reusable dimensions
- Build analytical DAX measures
- Implement Row Level Security (RLS)
- Validate model relationships and business logic
